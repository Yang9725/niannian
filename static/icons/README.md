# TabBar 图标说明

需要在此目录下添加以下图标文件：

## 相册图标
- `photo.png` - 未选中状态的相册图标 (81x81px)
- `photo-active.png` - 选中状态的相册图标 (81x81px)

## 上传图标  
- `upload.png` - 未选中状态的上传图标 (81x81px)
- `upload-active.png` - 选中状态的上传图标 (81x81px)

## 图标要求
- 尺寸：81x81 像素
- 格式：PNG
- 背景：透明
- 颜色：未选中状态建议使用灰色，选中状态使用主题色

## 临时方案
如果暂时没有图标，可以使用纯色的正方形图片作为占位符。
